# Memory Game

Простая игра на поиск одинаковых картинок для задания RS School.
На поле 16 карточек: 8 разных картинок, каждая встречается дважды.

## Как играть

- Откройте две карточки. Это один ход.
- Одинаковые картинки остаются открытыми. Разные закрываются через секунду.
- Найдите все 8 пар за наименьшее количество ходов.
- Кнопка «Новая игра» перемешивает карточки и обнуляет счётчики.
- После победы появится окно с количеством ходов.
- «Таблица лидеров» показывает 10 лучших результатов. При равенстве ходов выше стоит более ранняя игра.

Результаты сохраняются в `localStorage` браузера. Новая игра и перезагрузка
страницы не удаляют таблицу лидеров. Незавершённые игры не сохраняются.
Модальные окна можно закрыть кнопкой «Закрыть», кликом по фону или клавишей Escape.

## Локальный запуск

Сборка и установка зависимостей не нужны. Используются HTML, CSS и обычный JavaScript.

1. Склонируйте репозиторий и перейдите в ветку с игрой:

   ```bash
   git clone https://github.com/KirilPark99/memory-game.git
   cd memory-game
   git checkout memory-game
   ```

2. Запустите сервер из папки проекта (нужен Python 3):

   ```bash
   python3 -m http.server 8000
   ```

   На Windows можно использовать `py -m http.server 8000`.
   Также подойдёт расширение Live Server для VS Code.

3. Откройте <http://localhost:8000> в современном браузере.
   Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

Можно открыть `index.html` напрямую, но для предсказуемой работы сохранения
результатов лучше использовать локальный сервер и разрешить браузеру хранить данные сайта.

## Файлы проекта

- `index.html` — подключение стилей и скрипта. Вся разметка страницы создаётся в JavaScript.
- `style.css` — оформление страницы и модальных окон.
- `script.js` — создание элементов, перемешивание карточек, правила игры и таблица лидеров.
- `assets/` — восемь простых SVG-рисунков, сделанных для этой игры. Сторонние изображения не используются.
